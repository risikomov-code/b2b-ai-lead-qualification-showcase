# Public Showcase / Security Boundary

This repository is intentionally **not** a deployable copy of the production lead-qualification system.

## Public

- business problem
- high-level architecture
- qualification stages
- human-review pattern
- CRM-ready output concept
- privacy and validation principles
- non-sensitive case-study narrative

## Private

- prospect identities
- contact details
- profile URLs
- conversation history
- source exports
- scoring thresholds and weights
- prompts
- commercial tags
- CRM credentials
- workflow exports
- webhook URLs
- infrastructure details
- client data
- analytics
- outreach message library

No production prospect data, credentials or personal information should ever be committed to this repository.
